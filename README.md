# RestaurantAI - Operations Platform

Unified dashboard for restaurant managers and HQ operations teams integrating POS (Tabit), procurement (MarketMan/Restigo/Zester), and workforce (TabitShift/ShiftManager) data with AI-powered insights.

## Tech Stack
- React 18 + TypeScript
- Tailwind CSS v4
- shadcn/ui components
- Recharts for data visualization
- React Router v7 for routing
- Full Hebrew/English i18n with RTL layout support

## Getting Started

```bash
pnpm install
pnpm dev
```

## Features
- Operations Dashboard with 5 KPIs
- Anomaly Alerts with AI root cause analysis
- Daily AI-generated Action Plans
- Demand Forecasting (hourly + item level)
- Conversational AI Chat interface
- HQ multi-branch overview
- Data Management & integrations
- Full Hebrew/English i18n with RTL support
